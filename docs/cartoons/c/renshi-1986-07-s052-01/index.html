灌溉除虫
Watering and Removing Pests

Cartoon · Renshi (Personnel), 1986 no. 7 (whole no. 10) · back cover

Text in the drawing
培育人才 / 嫉才诬告 / 庆祝《人事》杂志创刊一周年
Nurturing talent / Envy and false accusation / Celebrating the first anniversary of Renshi magazine
Description
A man waters a tree (nurturing talent) and plucks off a pest labeled 'envy and false accusation'.
Note
